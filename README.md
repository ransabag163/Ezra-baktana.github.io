# עזרה בקטנה — האתר המעודכן

לצפייה באתר, פתחו את index.html בדפדפן.
להעלאה לאחסון, העלו את כל תוכן התיקייה יחד ושמרו על מבנה תיקיות assets ו־fonts.

הגרסה כוללת את הגרף המקורי, התאמות המובייל, משטחי הקריאה הלבנים ותיקוני השימושיות האחרונים. כל תוכן האתר נשמר.

קובצי העיצוב וההתנהגות ששמם כולל רצף אותיות ומספרים נמצאים בשימוש בעמודי האתר ואין למחוק אותם. רישיון הגופנים נמצא בתיקיית fonts.

אזור הפתרון עודכן לרקע בהיר רציף: הפסקאות מוצגות ישירות על הרקע, ארבע כרטיסיות לבנות עם מספרים כחולים וטבלת מחקר לבנה. כל התוכן נשמר.
