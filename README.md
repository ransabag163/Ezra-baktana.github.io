עדיין נחוצים לפני פרסום ציבורי: פרטי המפעיל, ערוץ פנייה פעיל לפרטיות ולנגישות, פרטי ספק האחסון ושמירת יומנים, בירור זכויות בתמונות ובציטוטים, ובדיקה משפטית ומקצועית של נגישות. החזרת התוכן אינה אישור לדיוק משפטי או לעדכניות ההשוואה. אין הבטחה לחסינות מתביעות. האפליקציה החיצונית לא שונתה. האישור להדגמה נבדק בדפדפן בלבד ואינו תיעוד הסכמה בצד שרת.

נוסחי הפתיחה, הפתרון, יעד המובייל, כיתוב הטבלה, הרגולציה והצגת האב־טיפוס מבחינים כעת בין השירות העתידי להדגמה הנוכחית. נוספו הבהרות למסעות המשתמש ולכל העמודים המשפטיים וההסכמה. לא הוסרו סעיפי מצגת, תמונות או שורות בטבלה.
